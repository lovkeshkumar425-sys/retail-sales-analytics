# Retail Sales Analytics

## 📌 Project Overview
This project focuses on analyzing retail sales data to understand sales performance, profitability, customer segments, product categories, and shipping performance. The analysis helps identify business trends and areas for improvement using Python, SQL, and Power BI.

## 🛠️ Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** MySQL
- **Power BI:** Interactive dashboard and data visualization
- **Excel/CSV:** Dataset handling

## 📊 Key Analysis
- Overall Sales, Profit, and Order Analysis
- Monthly and Yearly Sales Trends
- Category and Sub-Category Performance
- Regional Sales and Profitability
- Customer Segment Analysis
- Shipping Mode Performance
- Discount vs. Profit Analysis
- Top and Least Profitable Products
- Data Cleaning and Missing Value Analysis

## 📁 Dataset Details
- **Total Records:** 9,994
- **Total Columns:** 21
- **Dataset:** Retail Superstore Sales
- **Key Fields:** Order Date, Ship Date, Sales, Profit, Quantity, Discount, Category, Region, and Customer Segment

## 📈 Key Objectives
- Identify sales and profit trends.
- Understand which categories and regions perform best.
- Analyze the relationship between discounts and profitability.
- Evaluate shipping performance.
- Generate useful insights to support business decisions.
