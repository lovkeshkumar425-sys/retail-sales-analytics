# Retail Sales Analytics

## 📌 Project Overview
This project focuses on analyzing retail sales data to understand sales performance, profitability, customer segments, product categories, and shipping performance. The goal is to identify business trends and generate insights that support better decision-making.

## 🛠️ Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** MySQL
- **Power BI:** Interactive dashboard and data visualization

## 📊 Key Analysis
- Overall Sales and Profit Analysis
- Monthly and Yearly Sales Trends
- Category and Sub-Category Performance
- Regional Sales and Profitability Analysis
- Customer Segment Analysis
- Shipping Mode Performance
- Discount vs. Profit Analysis
- Top and Least Profitable Products
- Data Cleaning and Missing Value Analysis

## 📁 Dataset Details
- **Total Records:** 9,994
- **Total Columns:** 21
- **Dataset:** Retail Superstore Sales
